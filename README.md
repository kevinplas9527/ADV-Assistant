# ADV小助手 · 工程塑料重量计算

板、棒、管等材料形态的重量与成本快速测算工具，面向工程塑料行业的报价与备料场景。

## 功能

- **三种形态**：板材（长×宽×厚）、棒材（直径×长度）、管材（外径×内径×长度）
- **内置材料密度库**：PTFE、PFA、PVDF、PEEK、PPS、PI、POM、尼龙、PC、PMMA、ABS、HDPE、UHMWPE、PP、PVC 等常用工程塑料，支持手动修改密度
- **报价测算**：输入材料单价（元/kg）和数量，自动估算材料成本
- **一键复制**：结果可复制为文本，方便粘贴到微信、邮件或报价单

## 使用方法

直接用浏览器打开 `index.html` 即可，无需安装任何环境。

1. 选择材料（密度自动带出，可改）
2. 选择形态并填写尺寸（单位：mm）
3. 可选：填写单价（元/kg）与数量
4. 点击「计算」或按回车

## 计算说明

| 形态 | 体积公式 | 说明 |
|------|---------|------|
| 板材 | 长 × 宽 × 厚 | 尺寸单位 mm |
| 棒材 | π × (直径/2)² × 长度 | 圆棒 |
| 管材 | π × [(外径/2)² − (内径/2)²] × 长度 | 圆管，支持两种输入模式：按内外径，或按外径+壁厚（内径自动换算） |

- 体积单位：cm³；重量单位：kg（重量 = 体积 × 密度 / 1000）
- 密度单位为 g/cm³，**内置值为常用参考值，实际报价请按具体牌号的技术参数核对**

## 技术栈

纯前端实现（HTML + CSS + JavaScript），无任何外部依赖，数据全部在本地计算。

## 微信小程序版

小程序代码位于 `wxapp/` 目录，使用原生小程序框架，功能与网页版一致（板/棒/管计算、管材双输入模式、成本测算、结果复制）。

使用步骤：
1. 在 [微信公众平台](https://mp.weixin.qq.com) 注册小程序账号（企业主体用营业执照，个人主体用身份证）
2. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
3. 打开开发者工具 → 导入项目 → 选择 `wxapp/` 目录，填入你的小程序 AppID（暂无 AppID 可选"测试号"预览）
4. 模拟器预览、真机扫码调试
5. 工具栏「上传」→ 微信公众平台提交审核 → 审核通过后发布
